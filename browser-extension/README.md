# 啫喱小站课表助手

Edge / Chrome Manifest V3 扩展。用户在浙江理工教务系统登录后，主动点击扩展的“重新读取课表”授权本次读取；扩展显示课程预览，用户选择导入站点后，课表页再次预览并确认保存。

## 安装到 Edge

1. 打开 `edge://extensions`，启用“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择项目里的 `browser-extension` 文件夹。
3. 在同一 Edge 中登录教务系统，并打开个人课表页。
4. 点击扩展图标里的“重新读取课表”。只有这次点击会授权本次捕获；扩展随后刷新当前课表页并读取查询结果。刷新不会提交教务系统表单，也不会自动重复读取。
5. 再次点击扩展图标，检查课程预览，选择正式站或本地站，然后点击“预览并发送到本站”。
6. 在啫喱小站检查课程、周次、教室和作息；点击“确认并保存为私有课表”后才会写入账号。

Chrome 用户可在 `chrome://extensions` 使用相同步骤。

## 权限与数据

- 扩展只在用户点击“重新读取课表”后的两分钟内，在 `jwglxt-443.webvpn.zstu.edu.cn/jwglxt/kbcx/` 页面读取一次教务页面自身发出的课表响应；捕获成功或格式不支持后授权失效。
- 扩展没有 `cookies` 权限，不读取、复制或上传教务账号、密码、Cookie，也不替用户登录。
- 扩展只保留规范化的课程名、星期、节次、周次、教室和校区，不保存教务系统原始响应。
- 读取结果和待确认导入仅放在 `chrome.storage.session`，浏览器会话结束后清除；待导入 10 分钟过期。
- 课程传给本站前由扩展展示预览；保存前本站再展示一次，课表默认私有。
- 扩展需访问正式站 `www.furzl.cn` 或本地 `localhost` / `127.0.0.1` 页面，以便把已确认的课程交给本站课表页面。浏览器会在扩展安装时列出这些站点权限。

## 格式兼容

扩展监听个人课表查询的 JSON 响应，并识别常见教务字段：课程名 `kcmc`、星期 `xqj`、节次 `jcs`、周次 `zcd`、教室 `cdmc`、校区 `xqmc`，同时兼容若干通用字段别名。缺少必要的课程、节次或周次时会拒绝导入，不会推测缺失信息。系统页面改版或响应字段不同时，请继续使用 ICS/TXT 文件导入。

目前运行环境未提供已登录 Edge 标签页的读取能力，因此真实教务端响应字段尚未完成现场验收；模拟接口响应、字段解析及本站保存流程由项目测试验证。首次加载后若提示格式不支持，可从教务系统导出 TXT 并提供脱敏后的响应字段样例，再扩展适配器。
